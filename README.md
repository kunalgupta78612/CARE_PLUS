# 🏥 CarePlus HMS - Hospital Management System

A modern, high-performance, full-stack Hospital Management System built with **React**, **Vite**, **Tailwind CSS v4**, **TanStack Query**, and **Node.js**.

## 🌟 Key Features

- **Public Medical Landing Page**: Responsive hero banner, 24/7 emergency hotline, interactive department & specialist showcases, patient reviews, and clinic stats.
- **Online OPD Appointment Token Generator**: Zero-wait token generation with department & doctor selection.
- **Authentication & Role Security**: Pre-seeded multi-role accounts for **Admin**, **Doctor**, **Patient**, and **Receptionist / Staff**.
- **TanStack Query Integration**: Data fetching, background refetching, and optimistic mutations for medical appointments.
- **Responsive Light Mode Design**: Designed with glassmorphism, curated medical color palettes, and mobile drawer navigation.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/nainagupta6387-star/CARE_PLUS.git
   cd CARE_PLUS/frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173/` in your browser.

## 🛠️ Built With

- **Frontend**: React 19, Vite, Tailwind CSS v4, Lucide Icons, React Router DOM
- **Data & State**: TanStack Query v5 (@tanstack/react-query), React Context API
